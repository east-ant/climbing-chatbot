# 요금 안내 — ClimbMate 클라이밍 센터

## 기본 이용권

| 이용권 | 가격 | 설명 |
|--------|------|------|
| 일일권 | 15,000원 | 당일 무제한 이용, 클라이밍화 대여 포함 |
| 1개월 정기권 | 80,000원 | 30일 무제한 이용, 락커 포함 |
| 3개월 정기권 | 210,000원 | 90일 무제한 이용, 락커 + 장비함 포함 |
| 6개월 정기권 | 380,000원 | 180일 무제한 이용, 전체 혜택 포함 |

## 할인 혜택

| 구분 | 할인율 | 조건 |
|------|--------|------|
| 학생 할인 | 20% | 대학생 이하 학생증 제시 |
| 가족 할인 | 10% | 2인 이상 가족 동시 등록 |
| 조기 갱신 할인 | 10% | 만료 후 30일 이내 갱신 시 |
| 친구 추천 할인 | 15% | 기존 회원 추천 코드 입력 |
| 얼리버드 할인 | 5% | 매일 오전 6~8시 방문 등록 |

## 일일 체험 패키지

- **초보자 체험 패키지**: 25,000원
  - 일일 이용권 + 30분 기초 강습 + 클라이밍화 대여
  - 첫 방문 고객 전용
  - 사전 예약 권장

## 결제 방법

- 현장 결제: 카드, 현금, 카카오페이
- 온라인 결제: 홈페이지 또는 앱에서 카드 결제
- 자동 갱신: 월정액 회원 자동 결제 설정 가능

## 환불 규정

- 이용 시작 전: 전액 환불
- 이용 시작 후 7일 이내: 이용 일수 차감 후 환불
- 이용 시작 후 7일 초과: 환불 불가 (양도 가능)
